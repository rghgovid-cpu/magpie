# Ad Copy Skill

Use this skill to write paid media ads (Meta, LinkedIn, TikTok, Google Search).

## Platform limits (keep within these)

- Meta/IG/Facebook: primary text <=125 chars, headline <=40, description <=30.
- LinkedIn: intro text <=150, headline <=70.
- Google Search: headlines <=30 (x3), descriptions <=90 (x2).
- TikTok Spark: caption <=150, strong hook in first 3 seconds.

## Output format

- Hook options (scroll-stopping first line/headline)
- Body copy variants
- Headline(s)
- CTA
- Suggested image/video direction
- A/B testing matrix
