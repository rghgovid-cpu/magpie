# SEO Blog Post Skill

Use this skill to write blog content that ranks and converts.

## Workflow

1. Confirm the primary keyword + 2-3 secondary keywords.
2. Check search intent (informational / commercial / transactional).
3. Outline: H1 (primary keyword), H2/H3 sections answering People Also Ask.
4. Draft with keyword in first 100 words, H1, at least one H2, meta title <=60 chars, meta description <=155 chars.
5. Add internal link opportunities + external authoritative sources.
6. Suggest featured-image alt text and URL slug.

## Output format

- Title + slug
- Meta title / meta description
- Outline (H1/H2/H3)
- Draft body
- Internal linking suggestions
