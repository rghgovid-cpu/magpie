# Landing Page Copy Skill

Use this skill to write or review a landing page that converts visitors into leads or customers.

## Structure

1. Hero: headline (benefit-led), subheadline, hero image/video, primary CTA.
2. Problem / agitation: name the pain and the cost of inaction.
3. Solution: introduce the product as the answer, with the core mechanism.
4. Benefits (not just features): "so that you can..." outcomes.
5. Social proof: testimonials, logos, case studies, stats.
6. Pricing: plans + what's included, FAQ handling objections.
7. Final CTA + risk reversal (guarantee/trial).

## Output format

- Section-by-section copy with word counts
- Headline variants
- CTA button copy
