# Launch Email Skill

Use this skill when the user wants to write a product launch, feature announcement, or promotional email.

## Workflow

1. Identify the product, target audience, and the single goal of the email (e.g. sign-ups, pre-orders, awareness).
2. Draft 5-7 subject line options (under 50 characters, urgency + benefit).
3. Write a preheader that complements the subject line (no repetition).
4. Structure the body: hook -> problem -> product as solution -> proof -> CTA.
5. End with one clear CTA button/link and a P.S. with a deadline or bonus.
6. Suggest A/B test variants for subject line and CTA.

## Output format

- Subject lines (numbered)
- Preheader
- Email body (HTML-ready structure)
- CTA copy
- A/B test notes
